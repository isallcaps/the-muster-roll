The Muster Roll

A warband print sheet and reference tool for Trench Crusade. Paste a warband export from Trench Companion and get a print-ready model card for every soldier in your force — with keyword definitions, ability text, and equipment rules rendered inline so beginners can read and play from a single sheet without a separate cheat sheet.

Built On

  • Trench Companion — the official Trench Crusade community resource. Warband export JSON is generated from their tool.
  • Trench Crusade Data — game data (fork) powering all rule definitions, included as a git submodule. Extends the original repository with missing glossary entries, abilities, and variant rules sourced from the v1.0.2 rulebook PDFs.
  • Trench Crusade — the game itself. Visit the official site for the full rulebook and community.

Direct API loading is not available due to browser security restrictions (CORS). To load a warband: enter its ID in the toolbar, click Open API URL to open the raw JSON in a new tab, copy it, and paste it into the textarea. The warband ID appears in the Trench Companion URL — e.g. trench-companion.com/warband/detail/278648.

The Project

The Muster Roll is an open-source fan-made tool, not affiliated with or endorsed by the Trench Crusade team. All game content belongs to its respective rights holders.

Contributing

Data gaps spotted while using this tool — missing entries, mismatched IDs, incorrect rule text — are logged in DATA_DISCREPANCIES.md and fixed in the isallcaps/trenchcrusadedata fork where possible. Fixes flow back into this tool automatically via the submodule.
