The Muster Roll

A warband print sheet and reference tool for Trench Crusade. Paste a warband export from Trench Companion and get a print-ready model card for every soldier in your force — with keyword definitions, ability text, and equipment rules rendered inline so beginners can read and play from a single sheet without a separate cheat sheet.

Built On

  • Trench Companion — the official Trench Crusade community resource. Warband export JSON is generated from their tool.
  • Trench Crusade Data — the open game data repository powering all rule definitions, included here as a git submodule.
  • Trench Crusade — the game itself. Visit the official site for the full rulebook and community.

The Project

The Muster Roll is an open-source fan-made tool, not affiliated with or endorsed by the Trench Crusade team. All game content belongs to its respective rights holders.

Contributing

Data gaps spotted while using this tool — missing entries, mismatched IDs, incorrect rule text — are logged in DATA_DISCREPANCIES.md and reported upstream to the trenchcrusadedata repository. Fixes there flow back into this tool automatically via the submodule, helping improve the game data for everyone.
